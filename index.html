DuckGeneSnap

A backend-free GeneSnap-style genome snapshot: upload 23andMe text or VCF/BCF, join against curated Parquet assets with DuckDB, and use Rduckhts VariantKeys in the browser.

Static assets are locus-first: build + chrom + pos. variant_keys.parquet is auxiliary for allele-aware display, QA, and future exact-key refinement.

Not medical advice. This demo is informational only and uses a small curated asset bundle. Clinically significant results should be confirmed with clinical-grade testing and reviewed with a qualified professional.

Advanced VCF/BCF liftover assets

If the uploaded VCF/BCF build differs from the analysis bundle, DuckGeneSnap can call bcftools_liftover() in Rduckhts. Provide a chain file plus source and destination FASTA files. These files remain local in the browser VFS. For 23andMe files, matching remains build/chrom/position based.

Private by construction

There is no FastAPI, SQLite server, or upload endpoint. webR, DuckDB, and Rduckhts run inside the page.

VariantKey-first joins

Uploads are matched by genome build, normalized chromosome, and 1-based position using DuckDB indexes or Parquet row-group statistics.

Schema-ready liftover

When strict coordinate conversion is needed, recompute VariantKeys after Rduckhts liftover rather than lifting keys themselves.
