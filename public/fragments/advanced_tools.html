VCF/BCF liftover inputs

If the uploaded VCF/BCF build differs from the analysis bundle, DuckGeneSnap can call bcftools_liftover() in Rduckhts. Provide a chain file plus source and destination FASTA files, either as local files or HTTPS URLs that allow browser CORS downloads.

UCSC chain files are commonly available under hg19 liftOver and hg38 liftOver. Use the same source FASTA used to call the VCF and the matching destination reference; whole-genome FASTA URLs can be large and may fail if the host blocks CORS.

Why convert chip text to VCF?

23andMe-style text files usually carry rsID, chromosome, position, and genotype, but not a full REF/ALT representation. Direct text matching is useful for quick locus checks. For allele-aware interpretation, convert chip data to VCF with the correct genome build, reference FASTA, and chip manifest before using DuckGeneSnap.

  • Keep build metadata explicit: GRCh37 and GRCh38 positions are not interchangeable.
  • Use a trusted local converter or pipeline that records REF/ALT and preserves no-calls.
  • Then upload the VCF/BCF here so DuckGeneSnap can filter called alternate genotypes and compute VariantKeys.

LitVar2 live literature lookup

Query NCBI/NLM LitVar2 from the browser for rsIDs, variant names, or genes. If NCBI does not allow CORS for the current origin, DuckGeneSnap will show direct LitVar2 links instead of silently failing.
