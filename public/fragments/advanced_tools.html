Advanced local tools

These helper workflows are separate from annotation. Files and URL downloads are staged only inside the browser webR filesystem.

Loaded on demand

Convert a VCF/BCF to another build

Upload a VCF/BCF plus chain, source FASTA, and destination FASTA assets. DuckGeneSnap will run the Rduckhts bcftools_liftover() row kernel locally, normalize lifted variants, and download VCF, TSV, or Parquet. Upload the lifted output to the main annotation workflow when builds match.

Liftover status will appear here.

UCSC chain files are commonly available under hg19 liftOver and hg38 liftOver. Use the same source FASTA used to call the VCF and the matching destination reference. Whole-genome FASTA URLs can be large and may fail if the host blocks CORS.

23andMe text cleanup and VCF conversion

Upload chip text plus the matching reference FASTA. DuckGeneSnap uses DuckHTS UDFs to fetch REF bases, harmonize called SNP alleles, normalize variants, validate REF/ALT, and download a VCF plus QC TSV.

Chip conversion status will appear here.
